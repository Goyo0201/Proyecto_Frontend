# 🌐 Proyecto Frontend

Este proyecto es una página web desarrollada con HTML, CSS y JavaScript. Está diseñada como una práctica de desarrollo web y ha sido desplegada mediante **GitHub Pages**.

## 🛠️ Tecnologías utilizadas

Este proyecto fue desarrollado utilizando las siguientes tecnologías:

- **HTML5**: Para estructurar el contenido de la página.
- **CSS3**: Para los estilos y diseño visual responsivo.
- **JavaScript (vanilla)**: Para agregar interactividad a la página.
- **Git**: Para el control de versiones del proyecto.
- **GitHub**: Para alojar el repositorio y trabajar de forma colaborativa.
- **GitHub Pages**: Para desplegar el sitio web directamente desde el repositorio.
